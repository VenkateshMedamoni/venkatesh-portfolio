## 🚀 How to Deploy

### Option 1 — Tiiny.host (Fastest)
1. Go to [tiiny.host](https://tiiny.host)
2. Upload `index.html`
3. Name your site `venkatesh-medamoni`
4. Get your live link instantly → `venkatesh-medamoni.tiiny.site`

### Option 2 — Netlify (Recommended)
1. Go to [netlify.com](https://netlify.com) and sign up free
2. Drag & drop `index.html` into the deploy box
3. Rename domain to `venkatesh-medamoni.netlify.app`

### Option 3 — GitHub Pages (Most Professional)
1. Create a new **public** repository named `venkatesh-portfolio`
2. Upload `index.html` (rename it to `index.html` if needed)
3. Go to **Settings → Pages → Source → Deploy from branch → main**
4. Live at: `https://yourusername.github.io/venkatesh-portfolio`
